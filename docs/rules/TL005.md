# TL005: Tenant-scoped entity has no query filter

| Property   | Value              |
|------------|--------------------
| ID         | TL005              |
| Category   | TenantIsolation    |
| Severity   | Warning (see also TL105: Info when dynamic filter loop detected) |
| Enabled    | Yes                |
| Code Fix   | Yes (inserts non-compiling stub) |

## What it detects

TL005 fires when an entity type exposed as `DbSet<T>` on a `DbContext` has a property matching the configured tenant property names (default: `TenantId`) but the DbContext defines no `HasQueryFilter` that references that tenant property for the entity.

Discovery considers:
- **Explicit filters:** `HasQueryFilter(e => e.TenantId == ...)` in `OnModelCreating` or `IEntityTypeConfiguration<T>.Configure`.
- **Named filters (EF Core 10):** `HasQueryFilter("Tenant", e => e.TenantId == ...)`.
- **Inherited filters:** If a base entity type has a tenant filter, derived types inherit it (EF Core applies `HasQueryFilter` to the root entity of an inheritance hierarchy).
- **Non-tenant filters:** A `HasQueryFilter(e => !e.IsDeleted)` that does NOT reference the tenant property does not satisfy TL005.

## Severity logic

- **TL005** (Warning, default): The entity has `FilterState.Unfiltered` — no explicit or inherited tenant filter found.
- **TL105** (Info): The entity has `FilterState.Unknown` — a dynamic filter loop (`foreach` over `GetEntityTypes()` with `HasQueryFilter`/`SetQueryFilter`) was detected in the DbContext. Static analysis cannot confirm coverage. Verify manually.

## Why it leaks

An entity with a `TenantId` property but no global query filter will return data from **all tenants** in every LINQ query. This is the most common source of tenant data leaks in multi-tenant EF Core applications.

```csharp
// Without a query filter, this returns ALL customers across all tenants:
var customers = db.Customers.ToList();
```

## Examples

### Bad (Warning)

```csharp
public class Customer
{
    public int Id { get; set; }
    public string TenantId { get; set; } // tenant property exists
}

public class AppDbContext : DbContext
{
    // TL005: 'Customer' is tenant-scoped but has no query filter
    public DbSet<Customer> Customers { get; set; }
}
```

```csharp
// Non-tenant filter does NOT satisfy TL005:
public class AppDbContext : DbContext
{
    public DbSet<Customer> Customers { get; set; }

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        // This filters by IsDeleted, not by TenantId — TL005 still fires
        modelBuilder.Entity<Customer>().HasQueryFilter(e => !e.IsDeleted);
    }
}
```

### Informational (Info — TL105)

```csharp
public class AppDbContext : DbContext
{
    public DbSet<Customer> Customers { get; set; }

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        // Dynamic filter loop — TL105 (Info) instead of TL005 (Warning)
        foreach (var entityType in modelBuilder.Model.GetEntityTypes())
        {
            modelBuilder.Entity(entityType.ClrType)
                .HasQueryFilter(BuildFilter(entityType.ClrType));
        }
    }
}
```

### Good (no diagnostic)

```csharp
public class AppDbContext : DbContext
{
    private string _tenantId;
    public DbSet<Customer> Customers { get; set; }

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        modelBuilder.Entity<Customer>().HasQueryFilter(e => e.TenantId == _tenantId);
    }
}
```

```csharp
// Inherited filter from base type — no diagnostic:
public class BaseEntity { public string TenantId { get; set; } }
public class Customer : BaseEntity { }

public class AppDbContext : DbContext
{
    private string _tid;
    public DbSet<BaseEntity> BaseEntities { get; set; }
    public DbSet<Customer> Customers { get; set; }

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        modelBuilder.Entity<BaseEntity>().HasQueryFilter(e => e.TenantId == _tid);
        // Customer inherits the filter — no TL005
    }
}
```

```csharp
// Non-tenant entity — no diagnostic:
public class Country
{
    public int Id { get; set; }
    public string Name { get; set; } // no TenantId property
}
```

## Code fix

TL005 offers a code fix that inserts a `HasQueryFilter` stub into the DbContext's `OnModelCreating` method:

```csharp
modelBuilder.Entity<Customer>().HasQueryFilter(e => e.TenantId == TODO_SET_TENANT_ACCESSOR);
```

- If `OnModelCreating` does not exist, the code fix creates the override.
- `TODO_SET_TENANT_ACCESSOR` is intentionally undefined, producing compiler error CS0103. Replace it with your actual tenant accessor (e.g., `_tenantId`, `_currentTenant.Id`).
- The code fix is **not offered** when the entity is configured via `IEntityTypeConfiguration<T>`, because the filter should be added in the configuration class, not in `OnModelCreating`.

## How to suppress

```ini
[*.cs]
dotnet_diagnostic.TL005.severity = none
```

Or mark the entity as a global entity (never tenant-scoped):

```ini
[*.cs]
tenantlint.global_entities = AuditLog, Country
```

## False-positive notes

- **Global entities** (configured via `tenantlint.global_entities`) are excluded.
- **Entities without a tenant property** (no property matching `tenantlint.tenant_property_names`) are not flagged.
- **Entities not exposed as `DbSet<T>`** are not flagged (they must be reachable via a DbSet to be queried).
- **Inherited filters** are detected: if a base type has a tenant filter, derived types are not flagged.
- **Dynamic filter loops** reduce severity to Info (TL105) rather than producing a false positive.
- **IEntityTypeConfiguration filters** are recognized: if the filter is defined in a configuration class, TL005 does not fire.
