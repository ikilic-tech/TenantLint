# TL004: Tenant identity taken from client input

| | |
|---|---|
| **Category** | TenantIsolation |
| **Severity** | Warning |
| **Status** | Planned (v0.2) |

## What it will detect

Tenant identity bound from client input in ASP.NET Core: action or endpoint parameters whose name matches the tenant property list and that are bound via `[FromHeader]`, `[FromQuery]`, `[FromRoute]`, or `[FromForm]`; `Request.Headers["X-Tenant-Id"]`-style reads. Data-flow tracking (whether the value reaches a query) is deferred to v0.3; v0.2 reports the binding source regardless.
