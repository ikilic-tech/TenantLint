# TL203: Tenant isolation rules globally disabled

## What it detects

TL rules that are globally disabled via `<NoWarn>TLxxx</NoWarn>` in the project file or `dotnet_diagnostic.TLxxx.severity = none` in `.editorconfig`.

## Why it matters

Globally disabling a tenant isolation rule removes protection for the entire project. Individual suppressions with justification (`[CrossTenant("reason")]` or `#pragma`) are preferred because they document each exception.

## Examples

### Bad

```xml
<!-- In .csproj -->
<NoWarn>TL001;TL005</NoWarn>
```

```ini
# In .editorconfig
dotnet_diagnostic.TL001.severity = none
```

### Good

```ini
# In .editorconfig — lower severity instead of disabling
dotnet_diagnostic.TL001.severity = suggestion
```

## How to suppress

TL203 itself can be disabled in test projects where tenant isolation rules are intentionally not needed:

```xml
<NoWarn>TL203</NoWarn>
```

## False-positive notes

TL203 does not fire if only TL203 itself is suppressed (no infinite recursion).
