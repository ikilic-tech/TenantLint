# TL006: Cache key without tenant context

| | |
|---|---|
| **Category** | TenantIsolation |
| **Severity** | Warning |
| **Status** | Planned (v0.2) |

## What it will detect

`IMemoryCache`, `IDistributedCache`, or `HybridCache` set/get/`GetOrCreate*` calls whose key is a constant or an interpolation with no tenant-related value, inside a method that also touches tenant-scoped data.

## Contributions welcome

This rule is planned for v0.2. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for how to implement a new rule.
