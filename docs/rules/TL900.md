# TL900: Dynamic query filter detected

| Property   | Value              |
|------------|--------------------|
| ID         | TL900              |
| Category   | TenantIsolation    |
| Severity   | Info               |
| Enabled    | Yes                |

## What it detects

TL900 fires when TenantLint finds a `foreach` loop over `modelBuilder.Model.GetEntityTypes()` that applies query filters dynamically inside `OnModelCreating`. Because the analyzer cannot statically determine which entities are covered by the dynamic filters, it assumes all convention-based tenant entities in that `DbContext` have filters applied.

## Why it exists

When dynamic filters are detected, TenantLint cannot verify whether each tenant-scoped entity has a query filter (TL005). Rather than produce false positives, TL900 informs you that TL005 is disabled for that context.

## Example

```csharp
// TL900 reported on AppDbContext
public class AppDbContext : DbContext
{
    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        foreach (var entityType in modelBuilder.Model.GetEntityTypes())
        {
            entityType.SetQueryFilter(BuildFilter(entityType.ClrType));
        }
    }
}
```

## How to suppress

If this diagnostic is noise in your project, suppress it via `.editorconfig`:

```ini
[*.cs]
dotnet_diagnostic.TL900.severity = none
```
