# TL007: Tenant context stored in singleton

| | |
|---|---|
| **Category** | TenantIsolation |
| **Severity** | Warning |
| **Status** | Planned (v0.2) |

## What it will detect

Tenant context stored in a `static` field or property, or a type whose name contains `Tenant` (e.g. `ITenantContext`, `ICurrentTenant`) registered as `AddSingleton`. Also detects a singleton capturing a scoped tenant service in its constructor.

## Contributions welcome

This rule is planned for v0.2. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for how to implement a new rule.
