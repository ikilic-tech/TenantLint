# TL008: Background service without tenant scope

| | |
|---|---|
| **Category** | TenantIsolation |
| **Severity** | Info |
| **Status** | Planned (v0.2) |

## What it will detect

`BackgroundService`, `IHostedService`, or Hangfire job methods that resolve or inject a `DbContext` with tenant-scoped entities without creating a scope or setting the tenant first. This is a heuristic rule and defaults to Info severity.

## Contributions welcome

This rule is planned for v0.2. See [CONTRIBUTING.md](../../CONTRIBUTING.md) for how to implement a new rule.
