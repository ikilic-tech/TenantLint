# TL902: Class-level CrossTenant suppresses all methods

| Property   | Value              |
|------------|--------------------|
| ID         | TL902              |
| Category   | TenantIsolation    |
| Severity   | Warning            |
| Enabled    | Yes                |

## What it detects

TL902 fires when a `[CrossTenant]` attribute is applied at the class level. This suppresses tenant isolation checks (TL001-TL003) for **every** method in the class, which is almost always too broad.

## Why it exists

Class-level suppression silently exempts all current and future methods from tenant isolation analysis. As the class grows, new methods that should have tenant checks will be suppressed without any explicit decision. Method-level `[CrossTenant("reason")]` forces developers to justify each cross-tenant access individually.

## Examples

### Bad

```csharp
[CrossTenant("Admin service")]  // TL902: class-level suppression
public class AdminService
{
    public List<Customer> GetAllCustomers() { ... }
    public void UpdateCustomer(Customer c) { ... }  // silently exempted
}
```

### Good

```csharp
public class AdminService
{
    [CrossTenant("Admin dashboard aggregates data across all tenants")]
    public List<Customer> GetAllCustomers() { ... }

    public void UpdateCustomer(Customer c) { ... }  // still checked
}
```

## How to suppress

```ini
[*.cs]
dotnet_diagnostic.TL902.severity = none
```
