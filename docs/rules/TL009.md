# TL009: PostgreSQL RLS session variable without LOCAL

| | |
|---|---|
| **Category** | TenantIsolation |
| **Severity** | Warning |
| **Status** | Planned (v0.2) |

## What it will detect

PostgreSQL Row-Level Security session variable set with `SET app.<x>` or `set_config(..., false)` instead of `SET LOCAL` or `set_config(..., true)`. Without `LOCAL`, the session variable leaks across pooled connections.
