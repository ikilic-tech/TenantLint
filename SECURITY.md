# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in TenantLint, please report it through
[GitHub's private vulnerability reporting](https://github.com/ikilic-tech/TenantLint/security/advisories/new).

**Do not** open a public issue for security vulnerabilities.

## Scope

TenantLint is a static analysis tool. It cannot guarantee the absence of tenant
isolation issues — it catches common patterns at compile time. Always combine
static analysis with runtime safeguards and security testing.
